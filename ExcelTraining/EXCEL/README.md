# Excel Workshop Files

This folder contains the hands-on workshop files for **Class 1: Intermediate Excel Training**, structured as a 4-hour instructor-led course split across two workbooks.

## Files

### Class1_File1_BasicsFormatting.xlsx
**Sessions 1 & 2: Excel Basics, Working in Office, Data & Formatting** (~2 hours)

Covers navigation, the Excel interface, cloud workbooks, data formatting, and AutoFill.

| Sheet | Topic |
|---|---|
| **START HERE** | Course overview and session roadmap |
| **SalesData** | Shared source dataset (30 sales transactions) used across all exercises |
| **PT1-FormattedExample** | Pre-built example showing a properly formatted sales summary |
| **Lab1a-Navigate** | Navigation shortcuts and data entry practice |
| **Lab1a-ReferenceQuiz** | Cell reference identification exercises using the SalesData sheet |
| **Lab1b-CloudWorkbooks** | Saving to OneDrive/SharePoint, AutoSave, browser editing, and version history |
| **Lab2a-FormatData** | Hands-on formatting: headers, number formats, capitalization, Format Painter |
| **Lab2b-AutoFill** | AutoFill series, Flash Fill, and Paste Special |

### Class1_File2_Formulas.xlsx
**Session 3: Formulas & Basic Calculations** (~2 hours)

Covers arithmetic formulas, essential functions, absolute references, order of operations, and applied formula-building exercises.

| Sheet | Topic |
|---|---|
| **START HERE** | Session overview and workshop sequence |
| **SalesData** | Same source dataset as File 1 |
| **Lab3a-Arithmetic** | Basic arithmetic formulas (Total, Profit) using cell references |
| **Lab3a-Functions** | SUM, AVERAGE, MIN, MAX, COUNT practice |
| **Lab3a-AbsoluteRefs** | Absolute references with `$` for tax calculations |
| **Lab3a-PEMDAS** | Predict-then-verify exercises for order of operations |
| **Lab3b-SalesReport** | Build a quarterly sales report with totals and commissions |
| **Lab3b-BudgetAnalysis** | Budget tracker with remaining budget, % spent, and overage flags |
| **Lab3b-PredictVerify** | Formula result prediction scenarios (IFERROR, division by zero) |
| **Lab3b-FixFormulas** | Debug broken formulas: #VALUE!, #DIV/0!, #NAME? errors |
| **Challenge** | Capstone exercise combining formatting, formulas, functions, and references |
| **Quiz** | Knowledge check covering all Class 1 topics |
| **ANSWER KEY** | Instructor-only answer key (do not distribute to participants) |

## How to Use

1. Open the files in order: **File 1** first, then **File 2**.
2. Start on the **START HERE** sheet in each workbook for the session roadmap.
3. Complete the labs sequentially as the instructor progresses through each session.
4. The **SalesData** sheet is read-only source data shared across exercises -- do not modify it.
5. Hints are provided in each lab to guide learners, but try solving exercises independently first.

## Topics Covered

- Excel navigation and keyboard shortcuts
- Cloud workbooks (OneDrive, SharePoint, AutoSave)
- Cell formatting, number formats, and Format Painter
- AutoFill, Flash Fill, and Paste Special
- Arithmetic formulas and cell references
- Core functions: SUM, AVERAGE, MIN, MAX, COUNT
- Absolute vs. relative references
- Order of operations (PEMDAS)
- Formula debugging and error handling
