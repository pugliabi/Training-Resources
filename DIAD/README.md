# Getting Started with the DIAD Dataset

1. Download the DIAD.zip file in this folder
2. There is a single folder in the zip file - Extract it to the following location:

   C:\DIAD

3. You should have the following folder paths:

   ```
   C:\DIAD\A4
   C:\DIAD\Data
   C:\DIAD\Letter
   C:\DIAD\Reports
   ```

## Using the Data

All data is under the C:\DIAD\Data folder. 

The Excel file with dimensions is under
```
C:\DIAD\Data\USSales\bi_dimensions
```
The Sales files are under
```
C:\DIAD\Data\USSales\sales.csv
C:\DIAD\Data\InternationalSales\
```
